# User Guide

## Status

Per the README and `process/STATUS.md`: the specification set is a complete draft v1.0. Implemented
and audited: the crypto library, safe file handling, audit log, source-facing pages, intake store,
sealer, intake web service and host configuration (RM-0 to most of RM-2). The internal case zone is
partly started; later stages are not started. **Do not treat this repository as a working reporting
system for real sources.**

## Who this is for

- Readers who want to assess the design: start with `specs/DECISIONS.md`, `specs/02-THREAT-MODEL.md`,
  `specs/03-PRIVACY-ANONYMITY.md`, `specs/04-CRYPTOGRAPHY.md`, `specs/06-SYSTEM-ARCHITECTURE.md`.
- Reviewers of the security claims: `specs/REVIEW-REPORT.md` and `specs/39-REQUIREMENTS-TRACEABILITY.md`.
- Community edition licensing: `LICENSE` (AGPL-3.0-or-later for trust-path code, with exceptions listed there).

The static design preview is in `docs/` (GitHub Pages).
